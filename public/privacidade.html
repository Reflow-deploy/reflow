Política de Privacidade

Última atualização: 26 de setembro de 2026

O Reflow é um sistema web de gestão de espaços escolares (mapa de salas, reservas e ocorrências de infraestrutura), desenvolvido por alunos do curso de informática como projeto escolar. Esta página explica quais dados o Reflow usa, para que e como eles são protegidos.

1. Quais dados são usados

  • Login com o Google: nome, endereço de e-mail e foto de perfil da conta Google de quem entra no sistema.
  • Dados registrados pelos usuários: reservas de espaços (professor, turma, data e horário), ocorrências de infraestrutura (espaço, tipo de falha, prioridade, descrição e quem registrou) e cadastros de colaboradores (nome, categoria, função, e-mail, telefone, jornada e dias de trabalho) e de turmas.
  • Cargo de acesso: o papel de cada pessoa no sistema (Pendente, Professor, Equipe de Suporte, Direção ou Administrador).
  • Registros de auditoria: histórico dos e-mails de alerta enviados e das ações administrativas sensíveis (troca de cargo, exclusão de ocorrência e edição de sala).

2. Para que os dados são usados

  • Identificar quem está usando o sistema e controlar o que cada cargo pode ver e fazer.
  • Registrar e mostrar reservas, ocorrências e cadastros, atualizados em tempo real para os usuários autorizados.
  • Enviar por e-mail o alerta de uma nova ocorrência ao responsável escolhido.
  • Manter um histórico de auditoria para a segurança e a organização da instituição.

3. Uso do e-mail (Gmail)

O envio dos alertas é feito no servidor, por meio de uma conta de e-mail dedicada ao sistema, usando a API do Gmail exclusivamente para enviar mensagens de alerta. O Reflow não lê, não armazena e não compartilha o conteúdo das caixas de e-mail de nenhum usuário. O uso das informações recebidas das APIs do Google segue a Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Onde os dados ficam e com quem são compartilhados

Os dados ficam armazenados no Supabase (banco de dados PostgreSQL), e o site é hospedado na Vercel. O login é realizado pelo Google. Esses provedores são usados apenas para o funcionamento do sistema. Não vendemos dados e não os compartilhamos com terceiros para fins comerciais ou de publicidade. As informações de uma ocorrência são enviadas apenas ao responsável escolhido para recebê-la.

5. Segurança

  • O acesso é feito somente pelo login do Google, e contas novas ficam sem acesso até a aprovação de um Administrador.
  • O banco de dados aplica regras de segurança por cargo (Row Level Security), recusando leituras e alterações não autorizadas.
  • A comunicação usa HTTPS, e as ações administrativas sensíveis são registradas em auditoria.

6. Por quanto tempo os dados são mantidos e como excluí-los

Os dados são mantidos enquanto forem necessários para o funcionamento do sistema. Um Administrador ou a Direção pode excluir o cadastro de um colaborador, o que também remove a conta de login dele. Você pode solicitar a correção ou a exclusão dos seus dados pelo contato abaixo.

7. Seus direitos

Nos termos da Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018), você pode solicitar informações sobre os seus dados, a correção de dados incorretos e a exclusão dos dados pessoais tratados pelo Reflow.
